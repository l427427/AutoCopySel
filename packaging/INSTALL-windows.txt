AutoCopySel —— 鼠标划词自动复制
================================

【使用】
解压后双击 AutoCopySel.exe 即可，托盘区会出现图标。
不需要安装，也不需要额外授权。

【首次运行被拦】
Windows 会提示"Windows 已保护你的电脑"，点「更多信息」→「仍要运行」。
这是因为没有代码签名证书，不是病毒。

【验证是否可用】
打开任意软件，用鼠标选中一段文字，然后 Ctrl+V 粘贴试试。

【如果选中没反应】
右键托盘图标 →「运行诊断」，会告诉你哪一步没通。
常见原因：当前应用在终端黑名单里（cmd / PowerShell 等），
那里发 Ctrl+C 会打断进程，程序会主动跳过。

【卸载】
右键托盘图标退出，删掉 AutoCopySel.exe 即可。
配置与日志在 %USERPROFILE%\.autocopysel\，可一并删除。

详细说明见仓库 README。
